## Technical Overview

The Skill Grid platform, powered by Student Forge Technologies Private Limited, is a high-fidelity learning and internship ecosystem designed for technical career acceleration. This repository hosts the core platform architecture, featuring a high-density minimalist design language and durable workflow integrations.

### PRO-2.1.0 High-Density Architecture

The latest technical iteration (PRO-2.1.0) introduces:

- **Neutralized Typography**: All forced capitalization was purged in favor of a clean, high-contrast typography system designed for zero-friction scannability.
- **Vertical Density Optimization**: Navigation nodes were recalibrated to h-14 (Navbar) and h-10 (SubNavbar) to maximize content visibility across all viewports.
- **Architectural Watermarks**: Implementation of large-scale, low-opacity mission statements that anchor the platform's visual identity.
- **Durable Workflows**: Integration of the Workflow DevKit for resilient background operations and real-time mission status tracking.

## Platform Page Registry

The current ecosystem is composed of the following mission-critical page nodes:

### Core Hubs
- **/admin**: Centralized administrative terminal and mission control.
- **/ambassador**: Strategic lead program for campus vanguard leaders.
- **/community**: Collective intelligence board and innovation idea registry.
- **/docs**: Documentation hub for privacy, terms, and technical protocols.
- **/tools**: AI and Engineering accelerator toolkit for technical scaling.
- **/resources**: Academic knowledge base and open-source materials.

### Professional Internship Registry
- **/internships**: Definitive registry of mission-critical internship opportunities.
- **/internships/post**: Terminal for posting professional opportunities for students.
- **/intern**: Intern-specific dashboard for real-time mission tracking and certification.

### Academic Architecture (Academy)
- **/courses**: Academic enrollment and course management gateway.
- **/roadmaps**: Technical career path archives and roadmap terminals.
- **/dsa**: Data structures and algorithms mastery repository.
- **/certifications**: Professional achievement and verification hub.

### Engagement & Support Nodes
- **/get-started**: Entry portal for the integrated Skill Grid ecosystem.
- **/mentorship**: Leadership node and professional career guidance.
- **/events**: Hackathon, workshop, and technical event registry.
- **/projects**: Professional project showcase and student innovation hub.
- **/support**: High-fidelity support and mission-status helpdesk.

## Getting Started

### Development Environment

First, initiate the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to monitor the local instance.

### Technical Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS (Minimalist High-Density Utility)
- **Database**: Prisma with PostgreSQL
- **Emails**: Custom Mail Engine 2.1 (Resend / AWS SES compatible)
